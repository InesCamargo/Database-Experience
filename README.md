# Database-Experience

Entrega do **Desafio BootCamp Database Experience** com um script SQL único cobrindo:

- criação do esquema relacional;
- carga de dados de exemplo;
- consultas com `SELECT`, `WHERE`, atributos derivados, `ORDER BY`, `HAVING` e `JOIN`.

## Arquivo

- `bootcamp_database_experience.sql`

## Como executar (SQLite)

```bash
sqlite3 bootcamp.db < bootcamp_database_experience.sql
```
